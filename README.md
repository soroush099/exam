```markdown
#  پروژه پیش‌بینی سری زمانی (Time Series Forecasting)

این پروژه یک سیستم کامل برای **پیش‌بینی داده‌های سری زمانی** است.  
با استفاده از این ساختار می‌توانید داده‌های خود را بارگذاری، پاک‌سازی، استخراج ویژگی، آموزش مدل و پیش‌بینی نهایی را به‌صورت یکپارچه انجام دهید.  

---

## ساختار پروژه

```

│

│   ├── features/        # فیچر انجینیرینگ
│   │   └── feature\_engineering.py
│   ├── models/          # آموزش و پیش‌بینی مدل
│   │   ├── model\_training.py

````
## 🚀 نحوه اجرا

### 1️⃣ نصب وابستگی‌ها
ابتدا پکیج‌های مورد نیاز را نصب کنید:

```bash
pip install -r requirements.txt
````

### 2️⃣ آماده‌سازی داده

فایل داده خام (مثلاً `data.csv`) را داخل پوشه `data/raw/` قرار دهید.

ساختار داده مورد انتظار (مثال):

```csv
date,value
2020-01-01,120
2020-01-02,130
2020-01-03,125
...
```

### 3️⃣ اجرای پروژه

برای اجرای کامل پروژه از ابتدا تا انتها:

```bash
python main.py
```

این کار به‌ترتیب انجام می‌شود:

1. **لود داده** از `data/raw/`
2. **پردازش و فیچر انجینیرینگ**
3. **آموزش مدل و ذخیره آن در `models/`**
4. **پیش‌بینی سری زمانی آینده**
5. **ذخیره نتایج در `reports/metrics/`**
6. **ذخیره نمودارها در `reports/figures/`**
